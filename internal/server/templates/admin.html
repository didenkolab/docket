Why there is no button here

Granting access is not something this program can do. Anyone who can clone a repository has every task, every page and the whole history in it, and no check inside a web interface changes that. A button here would appear to hand out something it cannot. Access is granted on the host that holds each repository, where it is actually enforced.

What the roles mean: viewer reads. member creates tasks, moves them and comments. admin also changes what the vault calls things. They come from each host's own read, write and administer permissions rather than being invented here — and you may hold different ones in different repositories.
