Why there is no button here

Granting access is not something this program can do. Anyone who can clone the repository has every task, every page and the whole history, and no check inside a web interface changes that. A button here would appear to hand out something it cannot. Access is granted on {{$data.Host}}, where it is actually enforced.

What the roles mean: viewer reads. member creates tasks, moves them and comments. admin also changes the vault's vocabulary. They come from the host's own read, write and administer permissions rather than being invented here.
